# Changelog

## Expanded tracker build

This version expands the original Job Application Tracker with:

- Company and job-source records.
- Recruiter/contact management.
- Tasks and follow-up workflows.
- Notes, skills and tags.
- Application/contact, application/skill and application/tag relationships.
- Status transition history.
- User activity/audit records.
- Saved searches and preferences.
- CSV import and export.
- Pipeline, source, company, salary and workload analytics.
- Job-description parsing and transparent candidate/job keyword matching.
- Explainable application scoring.
- Duplicate detection.
- Search-expression parsing.
- Follow-up planning.
- Interview preparation checklists.
- Application age and interview lead-time reporting.
- Expanded React dashboard and reusable UI components.
- Expanded Spring Boot event-service validation, metrics and timeline APIs.
- Additional migrations and tests.
- Safer environment configuration.
